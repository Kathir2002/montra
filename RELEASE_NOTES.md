# Montra Finance App - Initial Release

## Key Features

- **Expense & Income Tracking**: Easily record and categorize all your financial transactions with a user-friendly interface
- **Deep Linking Support**: Directly access specific sections of the app through custom URLs
- **Push Notifications**: Stay on top of your finances with timely reminders and alerts
- **Multilingual Support**: Available in Tamil, English, Spanish, French, German, and Arabic

## Financial Management Tools

- Customizable categories for better expense organization
- Monthly budget planning capabilities
- Visual reports and charts for spending analysis
- Transaction history with search and filter functionality

## Technical Improvements

- Fast app performance with minimal resource usage
- Secure data storage with encryption
- Automatic data backup and sync between devices

## Getting Started

- Create an account or login with existing credentials
- Set up your initial budget and spending categories
- Enable notifications for important financial alerts
- Customize the app language in settings

## Known Limitations

- Cryptocurrency tracking will be added in a future update
- Desktop version currently in development
